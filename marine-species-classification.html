Computer Vision · Deep Learning done

Three ways to classify marine species, compared head to head

A six-person coursework project that put three deep learning approaches — a custom CNN, unsupervised autoencoder pre-training, and transfer learning — through the same marine species classification task, to see which assumptions actually held up.

Deep Learning Coursework

The setup

Rather than picking one architecture and tuning it, the project was built as a controlled comparison: run a custom CNN, an autoencoder-based unsupervised approach, and transfer learning against the same marine species dataset and see where each one actually breaks down. Working in a six-person team, the goal was as much about understanding relative strengths and failure modes as it was about raw accuracy.

The dataset came with real-world friction from the start — class imbalance and a scope that had to be adjusted once the original plan turned out to be computationally infeasible on the hardware available.

Approach

The comparison spanned custom CNN architectures, unsupervised learning with autoencoders, and transfer learning using pre-trained models — including VGG-style networks, ResNet50, and EfficientNet on top of ImageNet weights. Class imbalance was handled with weighted loss functions rather than just resampling.

Partway through, the toolchain moved from TensorFlow to PyTorch for better GPU compatibility, training on an RTX 3070.

What actually mattered

  • Model complexity has to match dataset size — the more expressive architectures overfit fastest when labeled data was limited.
  • Supervised learning clearly outperformed unsupervised pre-training once enough labeled data was available, which wasn't a given going in.
  • Transfer learning delivered the most reliable gains of the three, leveraging ImageNet pre-training rather than learning marine-specific features from scratch.
  • Scope has to flex with compute — when the original plan proved computationally infeasible, adjusting scope rather than forcing it through was what kept the comparison meaningful.
