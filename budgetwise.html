BudgetWise: a personal finance pipeline, built on data that fights back

The first in a planned three-project portfolio series, each mirroring the React + FastAPI stack from ER Navigator. This one turns a deliberately messy Kaggle personal-finance dataset into a categorization pipeline with an explainable decision layer.

Personal Project · Series 1 of 3

Why this dataset

Two versions of the BudgetWise Personal Finance dataset were available on Kaggle — a cleaned one and a messy one. I picked the messy one on purpose: inconsistent currency symbols (₹, $, Rs., INR), mixed date formats, and sentinel values standing in for missing data are exactly the problems a production pipeline actually has to handle.

Where it stands

  • Repo and environment set up, with a data / notebooks / src structure and profiling findings committed to GitHub.
  • Cleaning pass done: deduplicated records, regenerated reliable transaction IDs, normalized categories and payment modes, stripped currency symbols and converted amounts to numeric, and replaced sentinel values with proper nulls.
  • Date parsing across the dataset's multiple formats is designed and next up to run.

Coming next

  • Finish date parsing, then refactor the cleaning notebook into reusable functions.
  • Build the feature engineering layer.
  • Train a transaction categorization model with an explainable decisions layer.
  • Expose it through FastAPI and put a React dashboard on top.
